Machine Learning Models

Earthquake Prediction Model

Gradient Boosting Classifier

Parameter Value
Algorithm Gradient Boosting
Target Significant earthquake (mag ≥ 5.0) in next 24 hours
Features 60+ engineered features (temporal, seismic, spatial)
Training Data California earthquakes 2015-2024
Class Balancing SMOTE oversampling

Key Features

  • Temporal: Month, day, hour (cyclical encoding)
  • Seismic activity: Recent earthquake counts, magnitudes
  • Spatial: Distance from fault lines
  • Statistical: Rolling means, standard deviations
  • Lag features: Previous earthquake magnitudes

Flood Prediction Model

Random Forest Classifier

Parameter Value
Algorithm Random Forest
Target Flood event in next 7 days
Features 50+ engineered features (discharge, temporal)
Training Data River discharge 2010-2024 (5 sites)
Threshold 95th percentile of historical discharge

Key Features

  • Discharge statistics: Rolling means, percentiles
  • Temporal: Seasonal patterns, cyclical encoding
  • Trends: Rate of change, acceleration
  • Lag features: Previous days' discharge values
  • Extreme events: Days since last flood

Code Samples

1. Data Collection Example

from src.collectors.usgs_earthquake import USGSEarthquakeCollector

# Initialize collector
collector = USGSEarthquakeCollector()

# Fetch California earthquakes
df = collector.fetch_by_region(
    start_date='2024-01-01',
    end_date='2024-12-31',
    min_latitude=32.5,
    max_latitude=42.0,
    min_longitude=-124.5,
    max_longitude=-114.0,
    min_magnitude=2.5
)

print(f"Collected {len(df)} earthquakes")

2. Model Training Example

from src.predictors.earthquake_predictor import train_earthquake_model

# Train earthquake prediction model
predictor = train_earthquake_model(
    model_type='GradientBoosting',
    use_smote=True,
    use_grid_search=False
)

# Model is automatically saved to models/ directory

3. Alert Generation Example

from src.alert_system.alert_manager import AlertGenerator
from src.alert_system.notifier import NotificationHandler

# Initialize components
alert_gen = AlertGenerator()
notifier = NotificationHandler()

# Generate earthquake alert
alert = alert_gen.generate_earthquake_alert(
    probability=0.85,
    location="San Francisco Bay Area, CA",
    magnitude=6.2,
    depth=12.5
)

# Send notification
if alert:
    notifier.send_alert(alert, channels=['email', 'log'])
